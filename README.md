# BKN Infografis Generator

Aplikasi web ini dirancang khusus untuk **memudahkan para pegawai di lingkungan Badan Kepegawaian Negara (BKN)** dalam membuat dan menyusun infografis laporan kinerja harian secara cepat, praktis, dan berstandar resmi.

---

## 🎯 Manfaat untuk Pegawai BKN

1. **Memudahkan Pembuatan Laporan**:
   Pegawai tidak perlu lagi mendesain infografis dari nol. Cukup masukkan data capaian harian, dan sistem akan langsung menghasilkan infografis berstandar visual resmi BKN.

2. **Asisten AI Pintar**:
   Cukup tuliskan satu paragraf rangkuman kegiatan yang dikerjakan hari ini, AI akan otomatis membedah dan menyusunnya menjadi pilar kegiatan dan tabel capaian secara rapi.

3. **Data Identitas Terisi Otomatis**:
   Nama lengkap, jabatan/divisi, unit kerja, nama mentor/atasan, serta foto profil pegawai otomatis terpasang dari akun pengguna.

4. **Bukti Dokumentasi Visual**:
   Memudahkan pegawai melampirkan foto dokumentasi kegiatan atau tangkapan layar pekerjaan dengan keterangan pendukung.

5. **Siap Cetak & Bagikan**:
   Hasil infografis dapat langsung dicetak ke lembar PDF (ukuran A4 penuh) atau diunduh sebagai gambar PNG beresolusi tinggi (HD) untuk kebutuhan pelaporan cepat.
